# Mishra Vinay — Developer Portfolio

My personal portfolio website, featuring a scroll-driven 3D mascot character that rolls its way down the page.

**🌐 Live site: [portfolio-three-flax-81.vercel.app](https://portfolio-three-flax-81.vercel.app/)**

## Features

- 🎭 **Scroll-driven character animation** — a cartoon version of me stands in the hero and tumbles down into the About section as you scroll, cycling through 7 poses on a Three.js canvas
- ✨ **GSAP entrance animations** — smooth staggered reveal of the hero text with ScrollTrigger-powered motion
- 🃏 **Spotlight hover cards** — cursor-following glow effect on project and social cards
- 🚀 **Real projects** — current MERN CRM team project plus my GitHub work, each with what/why/when details
- ♿ **Reduced-motion support** — animations gracefully turn off for users who prefer less motion
- 📱 **Responsive** — static character fallback on mobile for performance

## Tech Stack

| Layer | Tools |
| --- | --- |
| Framework | Next.js 16 (App Router), React 19, TypeScript |
| Styling | Tailwind CSS 4 |
| 3D / Animation | Three.js, React Three Fiber, GSAP + ScrollTrigger |
| Deployment | Vercel |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.
